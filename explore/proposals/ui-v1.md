# Proposed map amendments from the v1 UI prototype

`map.md` stays the source of truth and is not edited here. Each row below is written in map.md's own format, so it can be pasted in as is. Rows marked **amends** add an "→ amended by" note to the named entry. The prototype is `ui-v1/live.html`, and the reasoning behind each call is in `ui-v1/DECISIONS.md`.

Evidence labels: **seen** means observed in the prototype or read in a vendor doc this session. **inferred** means reasoned from that. **guess** means neither.

| ID | Decision | Why | Source |
|---|---|---|---|
| V1 | **v0.1 ships two cameras, not one view: the iso working view (default) and the flat plan.** Orbit snaps to 45°. T toggles a true top-down plan. X explodes the selected machine in place. Elevation and section views stay out of v0.1. **Amends D1** ("plan view only"). R1 still holds, because the plan stays flat. | Every page of the prototype (Live, Blueprint, floor, Choices, Simulate, Replay, first run) was built and checked in iso, and none needed the plan to work [seen]. Machines that share a drawing are told apart by silhouette, gauges and mounted parts, which a flat plan reduces to rectangles [inferred]. The renderer takes azimuth and elevation as inputs, so the plan is a camera preset rather than a second renderer [seen, `build.mjs` `projectionFor`]. Cost in the real build is a guess. | Prototype |
| V2 | **Top means elevation 90° with zero extrusion.** The prototype stops at 89°, which leaves a sliver of height. The spec should fix it at 90° so R1 is exact. | R1 says flat. 89° is close but not flat [seen]. | Prototype |
| V3 | **Connect writes these exact settings.** Droid: `OTEL_TELEMETRY_ENDPOINT` and `OTEL_TELEMETRY_FORMAT=genai` as shell environment (Droid's `settings.json` has no `env` key), and the MCP server through `droid mcp add acan <url> --type http`, which writes `~/.factory/mcp.json`. Claude Code: `env` in `~/.claude/settings.json` with `CLAUDE_CODE_ENABLE_TELEMETRY`, `OTEL_METRICS_EXPORTER`, `OTEL_LOGS_EXPORTER`, `OTEL_EXPORTER_OTLP_PROTOCOL=http/json` and the endpoint, and the MCP server through `claude mcp add --transport http --scope user`, which writes `~/.claude.json`. Codex: `[otel]` with `exporter` and `trace_exporter` as `otlp-http` with `protocol = "json"`, and `[mcp_servers.acan]` with a `url`. **Amends E1.** | Droid: telemetry env vars, org-pinned `telemetry` block wins over them, and Factory's own export is unchanged [seen, docs.factory.ai enterprise/telemetry]. Droid MCP file and command [seen, docs.factory.ai cli/configuration/mcp]. Droid settings keys [seen, docs.factory.ai cli/configuration/settings]. Claude variable names [seen in search results for code.claude.com monitoring-usage]. Claude user-scope MCP lives in `~/.claude.json`, not `settings.json` [inferred, from memory of the Claude Code docs, not re-read]. Codex has an MCP client with streamable HTTP [seen in search results for developers.openai.com/codex/mcp]. Codex `protocol` field values [guess, check the Codex config reference]. | Prototype + vendor docs |
| V4 | **Agent signals differ, and the plant says so.** Droid sends spans to your own collector. Claude Code sends metrics and log events, not spans, so its turns are drawn from events. `codex exec` sends no metrics, so CI runs fall back to traces and transcripts. **Amends E1.** | Droid spans "only where you have configured a collector of your own" [seen, Factory telemetry doc]. Claude events [seen in search results]. `codex exec` gap [seen, title of openai/codex issue 12913]. | Vendor docs |
| V5 | **First run is one left panel with three steps: Read, Place, Connect.** The plant stays visible and fills in as readers finish. Confident matches appear grey on the plant, the rest wait as tray cards with the rule that fired and one question. Y always agrees with Acan's guess. Nothing is written until you continue, and the yaml draft is shown live. The first signal from an agent lights the plant with its real states. **Refines K5 and D10.** | Prototype pages f1 to f11 [seen]. One variant was built, not three. The layout is fixed by the payoff of watching the plant fill in, and what is left open is copy and order, which a second layout would not settle [inferred]. | Prototype |
| V6 | **Update checks are off until the user turns them on.** Crash reports ask each time. The egress pill reads "0 out" from first launch. **Refines Q16.** | A closed app that phones home on first launch spends its trust before the user has seen anything [inferred]. The cost is that users on old builds stay there until they opt in [inferred]. | Prototype |
| V7 | **Ctrl K ships as a lexical jump in v0.1. The answer area moves to v0.2.** | D1 does not list it. The research keeps generated answers behind a Tier 1 selector that must first beat the Tier 0 scorer on a replay test, and that test cannot run before v0.1 has users [seen, `research/generative-ui.md`]. The launch video (U3) is served by the jump, Tab and the inspector [inferred]. | Prototype + research |
| V8 | **Generated content appears only in named, fixed slots** (the inspector "Now" slot and up to three canvas callouts in v0.1). A selector picks among candidates the core built, and never writes numbers, labels, prose or positions. v0.1 ships the deterministic Tier 0 scorer only. One setting turns adaptive slots off. **New A11.** | Full text and sources in `research/generative-ui.md`, proposal A11. | Research |
| V9 | **Labels never overlap.** Visible chips are laid out every frame. Selected, failing and strained machines keep their place, and the rest lift on a longer leader line until clear. A chip that only shows on hover moves itself, not its neighbours. | Fit zoom had intake over gate and paypal over github in every mode [seen]. After the pass, 18 chips with readings showed and none overlapped [seen, measured in the prototype]. | Prototype |
| V10 | **Fog is a layer, off by default.** A machine's fog score is 1 minus the mean of six signals, and it grows back as commits make a seal stale. Patches under 0.2 stay faint and unlabelled. Below 55% zoom, chips collapse to their badges. **Refines K12.** | Prototype, `fog.mjs` [seen]. The six signals and the 0.2 threshold are guesses to tune against the three fixtures. | Prototype |
| V11 | **Share-safe export previews the redaction on the plant** and counts only the classes the view draws. Paths, ports and env names are absent from the plant, so the panel says so instead of showing zero. **Refines S3 and R2.** | Prototype, `share.mjs` [seen]. | Prototype |
